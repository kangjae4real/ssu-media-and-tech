# SSU Media and tech
## Abstract
Soongsil University Media and tech lecture code repository

## Installation
### Install node.js in macOS(with homebrew)
```shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### Install node.js in Windows
[Web](https://nodejs.org/)

## Paste base code
```shell
npx ssu-media-and-tech-starter
# ...
# Need to install the following packages:
# ssu-media-and-tech-starter@1.0.5
# Ok to proceed? (y) y
#
# ✔ 프로젝트 이름을 입력하세요: project
# 'project' 프로젝트를 생성합니다...
# 프로젝트 생성이 완료되었습니다!
# 아래 명령어를 실행하여 프로젝트를 시작하세요:
# cd project
# bun install
# bun run dev
```

## Run
```shell
npm install
npm dev
```
